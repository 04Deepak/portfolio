About

How I work

I'm a full-stack developer who kept following the code past the merge button. Most of what I've shipped in the last two years started as a requirements document and ended as containers running on a cluster I set up — so I've spent as much time in kubectl and ArgoCD as in an editor.

The work I'm proudest of is unglamorous: finding out that a chat bug was a Socket.IO reconnect listener bound to the wrong object, that a kubelet crash was fstab re-enabling swap after a reboot, or that a "network" problem was actually a Postgres password failure. Root cause over workaround, every time.

I default to self-hosted and cost-conscious infrastructure, keep secrets in a managed store rather than in build config, and write the documentation as I go — threat models, architecture decisions, runbooks. I read English, Hindi and Marathi, and I'm based in Pune.
